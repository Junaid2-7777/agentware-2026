# Agentware 2026

**The challenge:** Build an AI agent that finishes a useful job on its own, takes a real action in a safe environment, and knows when to stop. A chatbot or a canned demo isn't enough.

**Deadline:** Monday, November 30 at **11:30 p.m. IST** (18:00 UTC). The build window opened Friday, November 27 at the same time. All project code must be new and written during that window.

## What to submit

1. A **public repo** with an OSI-approved license (MIT or Apache-2.0 are recommended). Judges should be able to run it in **under 15 minutes**, without giving it their personal credentials.
2. A **video up to 3 minutes** showing one real run from trigger to result with no human intervention.
3. The project, all registered team members (solo or up to four), and **one track**, via the [submission form](https://tally.so/r/WJzRbk). One person submits for the team.
4. In the repo: a run trace, model/tool notes, safety controls, and actual [Trap Pack](https://agentwarehack.com/trap-pack/) results in `tests/`. Report failures honestly. No secrets, real-user messages, or uncontrolled spending.

## What earns points

Autonomy **30%** · Usefulness **25%** · Reliability **20%** · Engineering **15%** · Demo **10%**.

Up to **4 extra points**: enforced guardrails, live monitoring, a working kill switch, and an audit trail. The cash pool is **$1,800**, including **$800 for first** and **$100 for Best Kill Switch**.

**Tracks:** Inbox & Calendar, Life Admin, Research & Study, Browser Agent, Developer Workflow, Open Track.

Start with the [official brief](https://agentwarehack.com/brief/) or its [plain-English version](https://agentwarehack.com/brief/#explain-full). The [planning docs](docs/) cover the candidate ideas, comparison, and build plan. This README is an event guide, not a claim that the product is built.
