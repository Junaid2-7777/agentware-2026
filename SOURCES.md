## Key requirements

Build an AI agent that completes useful work unattended and takes a real action through a tool. Submit one track, a public repository under an OSI-approved license and a video up to three minutes showing a genuine run from trigger to result. A judge must be able to set it up in under 15 minutes and inspect its run trace. Everyone on a team of up to four registers individually. No pre-kickoff project code or committed credentials. The window is November 27–30, 2026, 18:00 UTC on both dates (11:30 p.m. IST).

Scoring: autonomy 30%, usefulness 25%, reliability 20%, engineering 15%, demo 10%. Four optional points cover code-enforced guardrails, live monitoring, a kill switch and an audit trail. The Trap Pack evaluates reliability; report outcomes and limitations, not just passes.
